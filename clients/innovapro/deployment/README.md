# Plantillas, no instaladores automáticos

`nginx.example.conf` es una referencia para el administrador del servidor. Ajustar PHP/socket, rutas, certificados, usuario, logs y proxy. Seguir [DEPLOY.md](../docs/DEPLOY.md) para Apache, LiteSpeed/OpenLiteSpeed o Nginx. No sobreescribir configuraciones generadas por el panel.

El paquete **no** crea DNS, certificados, bases, usuarios, cron ni campañas. No incluye un instalador web expuesto o un setup.php con secretos.
